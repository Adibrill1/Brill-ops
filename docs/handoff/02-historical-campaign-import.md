# Historical Campaign Import

Attached to this handoff is a complete collection of materials from a previously completed campaign.

These files are **not reference material only**.

Treat them as the source data for importing the first historical campaign into the Brill Ops platform.

## Requirements

- Create a campaign record from the supplied materials.
- Set its status to **Archived**.
- Import all available information into the database.
- Preserve the original campaign dates.
- Preserve all participant information.
- Preserve all teams.
- Preserve all uploaded media.
- Preserve all available statistics.
- Preserve campaign branding whenever possible.

If some information is missing from the source material, create reasonable placeholders while clearly marking them as estimated.

The imported campaign should appear in the Archive exactly as if it had originally been created through Brill Ops.

The Archive should therefore be fully functional from the very first version of the platform.
